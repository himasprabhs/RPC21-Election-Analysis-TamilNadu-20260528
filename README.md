# Resume Project Challenge 21: Help AtliQ Media to Decode the 2026 Tamil Nadu Election

## 💼 About
- Domain: Media/Broadcasting
- Function: Media

## 🤔 Problem Statement

AtliQ Media is producing an one-hour TV show on the 2026 Tamil Nadu Assembly election results. I have been hired as a data analyst 
to find the most interesting stories in the 2026 results, pick the right numbers, support each with a clear chart, and pitch them in a way 
that helps AtliQ plan with a clean, fact-based show grounded only in ECI data. And Frame them so a regular viewer understands, and holding 
their attention without using complicated charts.
